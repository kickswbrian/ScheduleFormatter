Paste Course Listings

In NYU Albert, browse a course, then select all & copy the entire page text and paste it below. Repeat for as many courses as you want — just keep appending.

⚡ Use directly on Albert (Chrome Extension)

  1. Download the extension folder that came with this file
  2. Open Chrome and go to chrome://extensions
  3. Turn on Developer mode (top-right toggle)
  4. Click Load unpacked and select the extension folder
  5. Navigate to any Albert course listing — click the NYU icon in your toolbar

The overlay pops up instantly with filters — no copy-paste needed.
